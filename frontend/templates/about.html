{# ── Features grid ─────────────────────────────────────────────────────── #}

Features

{# Dashboard #}

Dashboard & System Monitor

Real-time Nginx status, CPU, RAM, and network bandwidth with animated SVG ring gauges. Auto-refreshes every 5 seconds.

{# Config Manager #}

Config Manager

Create, edit, and delete Nginx server blocks in sites-available. CodeMirror editor with Nginx syntax highlighting, code folding, and Ctrl+S to save. Runs nginx -t validation before every save.

{# Site Toggle #}

Site Enable / Disable

Toggle sites on and off instantly by managing symlinks in sites-enabled. Status is reflected live on the config list.

{# SSL Manager #}

SSL Certificate Manager

View expiry dates, days remaining, and status badges for all certificates. Upload new SSL files via drag-and-drop. Edit .crt and .key files directly in the browser.

{# Log Viewer #}

Log Viewer

Dark terminal-style viewer for access and error logs. Color-coded by HTTP status and log level. Live search, status / level filter pills, browser & OS detection from User-Agent, horizontal scroll, sticky column headers, and auto-refresh.

{# Nginx Controls #}

Nginx Controls

One-click Reload Nginx available on every page. Uses nsenter to reach the host's systemd from inside the Docker container without privileged socket hacks.

{# User Management #}

User Management & Roles

Add, edit, and delete users. Two roles: Admin (full access) and Viewer (read-only). Safeguards prevent deleting the last admin or your own account. Users stored in a JSON file — no database required.

{# Auth #}

JWT Authentication

All routes protected by JWT tokens stored in httpOnly cookies. Passwords hashed with bcrypt. Configurable token expiry and secret key via environment variables.
