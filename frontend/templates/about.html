{# ── Features ──────────────────────────────────────────────────────────── #}

All Features

{# Dashboard #}

Dashboard & System Monitor

Real-time Nginx status, CPU, RAM, disk usage, and network I/O with animated SVG ring gauges. Fully node-aware — shows metrics for whichever node is selected. Auto-refreshes every 5 seconds.

{# Config Manager #}

Config Manager

Create and edit Nginx server blocks directly in sites-enabled — changes are live immediately. Disabling a site archives it to sites-available instead of deleting it. CodeMirror editor with Nginx syntax highlighting, code folding, and Ctrl+S to save. Runs nginx -t before every save. Works on local and remote nodes.

{# Proxy Builder #}

Proxy Manager & Builder

Visual UI to create and manage reverse-proxy server blocks — no raw Nginx syntax needed. Fill in domain, upstream port, SSL toggle, and location rules; the builder generates a validated config file. Supports local and remote nodes. Enable/disable with one click.

{# Multi-Node #}

Multi-Node Management

Add unlimited remote Ubuntu servers as nodes. SSH via username+password or private key. Switch the active node from the sidebar — all pages (Dashboard, Configs, Proxy, SSL, Logs, Backup) instantly show that node's data. Live ping status dots in the sidebar. Remote Nginx reload with one click.

{# Site Toggle #}

Site Enable / Disable

Toggle sites on/off by managing symlinks in sites-enabled. Works on both local and remote nodes. Status reflected live in the config and proxy lists. Nginx is reloaded automatically after each toggle.

{# SSL Manager #}

SSL Certificate Manager

View expiry dates, days remaining, and status badges for all certificates. Upload new SSL files via drag-and-drop. Edit .crt and .key files in the browser. For remote nodes, lists certs from /etc/ssl/private, /etc/nginx/ssl, and /etc/letsencrypt/live via SSH.

{# Log Viewer #}

Log Viewer

Dark terminal-style viewer for access and error logs — up to 500 lines at a time. Color-coded by HTTP status and log level. Live search, filter pills, browser & OS detection from User-Agent, auto-refresh. Node-aware: fetches logs from the selected node over SSH.

{# Backup #}

Backup & Restore

One-click tar.gz backup of all sites-enabled and sites-available configs. Schedule auto-backups (hourly, daily, weekly) with configurable retention. For remote nodes, files are fetched over SFTP and stored locally. Restore any backup instantly. Backup history with kind badges (manual, scheduled, remote).

{# Testing Suite #}

Testing Suite (4 tabs)

  • SSL Check — expiry, TLS version, cipher grade, SAN list
  • Security Headers — HSTS, CSP, X-Frame-Options, referrer policy & more
  • Load Test — up to 1 000 requests / 500 concurrency; sparkline chart, p90/p99, RPS
  • API Security — HTTPS enforce, auth check, CORS wildcard, TRACE method, rate-limit headers, server info leakage, sensitive data in body, cache-control
{# Nginx Controls #}

Nginx Controls

One-click Reload Nginx available on every page, for both local and remote nodes. Uses nsenter to reach the host's systemd from inside Docker. Remote reload runs systemctl reload nginx over SSH with sudo.

{# User Management #}

User Management & Roles

Add, edit, and delete users. Two roles: Admin (full access) and Viewer (read-only). Safeguards prevent deleting the last admin or your own account. Users stored in a JSON file — no database required.

{# Auth #}

JWT Authentication

All routes protected by JWT tokens stored in httpOnly cookies. Passwords hashed with bcrypt. Configurable token expiry and secret key via .env. Active node selection persisted in a separate active_node cookie.

{# ── Node-Aware Architecture note ──────────────────────────────────────── #}

Node-Aware Design

All pages read the selected node from the active_node cookie, set globally by the sidebar node switcher. Selecting a remote node causes every page — Dashboard metrics, Configs, Proxy Manager, SSL, Logs, and Backup — to fetch and display data exclusively from that node via SSH/SFTP. Switching back to Local immediately returns to the host server. Data from different nodes is never mixed.
